# Жижиг Статик Веб Сайт (Бие даалтын ажил)

Энэхүү төсөл нь веб программчлалын суурь болон Git/GitHub-ийн үндсэн workflow-ийг турших зорилготой статик веб сайт юм.

## Файлын бүтэц
- `index.html` - Нүүр хуудас
- `about.html` - Бидний тухай хуудас
- `contact.html` - Холбоо барих хуудас
- `style.css` - Веб сайтын загвар, дизайн
- `script.js` - Интерактив функцүүд
- `README.md` - Төслийн баримт бичиг

## Ашигласан технологиуд
- HTML5
- CSS3
- JavaScript (ES6)
- Git & GitHub
